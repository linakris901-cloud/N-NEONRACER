# NEON RACER ULTIMATE — Garage & Credit Update

Браузерная аркадная гонка на HTML, CSS и JavaScript. Дополнительно включён необязательный Python-сервер для локального SQLite-снимка игровой экономики.

## Быстрый запуск

1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. В режиме без сервера монеты, покупки, состояние машин и долг сохраняются в `localStorage` браузера.

## Запуск с Python-сервером

Требуется Python 3.9+; сторонние библиотеки не нужны.

```bash
python server.py
```

Откройте `http://127.0.0.1:8000`. Сервер раздаёт сайт и сохраняет копию баланса, коллекции и кредитной задолженности в `economy.sqlite3`. Фронтенд продолжает использовать `localStorage` как основной источник состояния и отправляет снимок на сервер при изменениях экономики.

## Экономика

- Монеты: +25 за подобранную монету на трассе и дополнительная награда по результату заезда.
- Покупка автомобилей: цены отображаются на карточках; VOLT GT доступен сразу.
- Ремонт: 3 монеты за каждый процент прочности, который нужно восстановить.
- Кредитный лимит: 3 000 монет. Комиссия 15% добавляется к долгу при выдаче займа; повторного ежедневного начисления процентов нет.
- Долг погашается игровыми монетами через кредитный центр.
- Все данные — только игровая валюта, без реальных денег и платежей.

## Файлы

- `index.html` — разметка интерфейса.
- `css/style.css` — стили, улучшенные SVG-иконки гаража и кредитного центра.
- `js/game.js` — игровая логика, покупки, монеты, ремонт и кредиты.
- `icons.svg` — отдельный набор SVG-символов для интерфейса.
- `server.py` — необязательный сервер на Python и SQLite.

Рекорды и данные браузерного режима локальны и не синхронизируются между устройствами. Сервер рассчитан на локальную одиночную игру, не публикуйте его напрямую в интернет.

## Обновление: уникальные машины и препятствия
- В игровом поле автомобили получили отличающиеся силуэты по классам (спорткар, гиперкар, внедорожник, драгстер) и индивидуальные раскраски/полосы для каждой модели.
- Добавлены препятствия: деревянный ящик, шина, дорожные работы, лазерный барьер и летающий дрон.
- Новые препятствия включены в генерацию с учётом сложности; экстремальный режим чаще встречает опасные объекты.
- У разных препятствий разный урон состоянию автомобиля.


## Обновлённая графика автомобилей

- Игровые автомобили отрисовываются на Canvas с градиентным лакокрасочным покрытием, отражениями на стекле, более детальными колёсами и дисками, тенями, швами кузова и вентиляционными прорезями.
- Сохраняются уникальные силуэты и ливреи шести моделей; изменения не требуют внешних файлов или подключения к сети.
- При выборе художественного направления проверены CC0-пакеты OpenGameArt: [2D Race Cars](https://opengameart.org/content/2d-race-cars) и [Racing Pack](https://opengameart.org/content/racing-pack). Эти наборы не копировались в проект.


## Обновление прогрессии и трассы

- При первом запуске доступен только VOLT GT; остальные машины закрыты и покупаются за внутриигровые монеты.
- Монеты начисляются после заезда в зависимости от результата; прогресс хранится в localStorage.
- Уличные огни и дорожные маркеры расставлены реже, разметка и асфальт стали мягче и визуально спокойнее.
- Препятствия появляются реже, чтобы трасса не выглядела чрезмерно загруженной.

## Мультиплеер по сети (новое)

В проект добавлены комнаты WebSocket для гонок с друзьями: до 8 игроков, создание комнаты, вход по коду, список участников и передача положения/скорости/цвета машины в реальном времени. Машины других игроков отображаются на трассе.

### Запуск сервера

Требуется Node.js 18 или новее. В каталоге проекта выполните:

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. Нажмите **СОЗДАТЬ** в блоке «Мультиплеер» и отправьте код комнаты другу. На другом компьютере в той же сети нужно открыть `http://IP-АДРЕС-КОМПЬЮТЕРА-С-СЕРВЕРОМ:3000` и ввести код. Разрешите входящие подключения к порту 3000 в брандмауэре, если система спросит.

Чтобы играть через интернет из разных сетей, сервер необходимо развернуть на Node.js-хостинге с поддержкой WebSocket и HTTPS/WSS; статического хостинга недостаточно. В браузере с HTTPS используется защищённое WebSocket-соединение автоматически. Комнаты временные, хранятся в памяти сервера и удаляются после выхода всех игроков. Текущая версия синхронизирует присутствие и позиции автомобилей; физика препятствий и счёт каждого клиента остаются локальными. Не публикуйте сервер в интернет без дополнительной защиты/ограничений.
